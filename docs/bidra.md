# Bidra och rapportera

## Var hör ärendet hemma?

| Gäller | Skapa issue i |
| --- | --- |
| Bastion för Apple | [Nytt issue](https://github.com/pissmyran/bastion_apple/issues/new/choose) |
| Bastion för Linux | [Nytt issue](https://github.com/pissmyran/bastion_linux/issues/new/choose) |
| Bastion för Windows | [Nytt issue](https://github.com/pissmyran/bastion_windows/issues/new/choose) |
| Bastion för Android | [Nytt issue](https://github.com/pissmyran/bastion_android/issues/new/choose) |
| Alla plattformar, synkformatet eller den här sajten | [Bastion](https://github.com/pissmyran/bastion/issues/new/choose) |

Är du osäker, skapa det här. Det flyttas till rätt repo.

## Projektet

Projektet [Bastion](https://github.com/pissmyran/bastion/projects) samlar ärenden och pull requests från alla fem repona. Fältet **Plattform** visar vilket repo ett ärende hör till.

## Säkerhetsproblem

Rapportera aldrig en sårbarhet i ett publikt issue. Följ [SECURITY.md](https://github.com/pissmyran/bastion/blob/main/SECURITY.md) och använd privat sårbarhetsrapportering i det berörda repot.

## Bidra med kod

Kod ändras i plattformens repo, inte här. Varje repo har en `CONTRIBUTING.md` och en `CLAUDE.md` med kommandon och regler. Reglerna för alla repon står i [STYRNING.md](https://github.com/pissmyran/.github/blob/main/STYRNING.md).
