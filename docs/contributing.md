# Contribute and report

## Where does the issue belong?

| Concerns | Open the issue in |
| --- | --- |
| Bastion for Apple | [New issue](https://github.com/pissmyran/bastion_apple/issues/new/choose) |
| Bastion for Linux | [New issue](https://github.com/pissmyran/bastion_linux/issues/new/choose) |
| Bastion for Windows | [New issue](https://github.com/pissmyran/bastion_windows/issues/new/choose) |
| Bastion for Android | [New issue](https://github.com/pissmyran/bastion_android/issues/new/choose) |
| Every platform, the sync format or this site | [Bastion](https://github.com/pissmyran/bastion/issues/new/choose) |

If you are unsure, open it here. It will be moved to the right repo.

## The project

The project [Bastion](https://github.com/pissmyran/bastion/projects) gathers issues and pull requests from all five repos. The **Repository** column shows which repo an item belongs to.

## Security problems

Never report a vulnerability in a public issue. Follow [SECURITY.md](https://github.com/pissmyran/bastion/blob/main/SECURITY.md) and use private vulnerability reporting in the affected repo.

## Contributing code

Code changes go into the platform's repo, not here. Each repo has a `CONTRIBUTING.md` and a `CLAUDE.md` with commands and rules. The rules for every repo are in [GOVERNANCE.md](https://github.com/pissmyran/.github/blob/main/GOVERNANCE.md).
